## 通信协议速查

| 参数 | 值 |
|------|-----|
| 物理接口 | USB 转串口（CH9102F），K7 端设备节点 `/dev/ttyUSB*` |
| 波特率 | 115200 |
| 下行帧（K7→STM32） | 11 字节：0x7B + 模式 + 预留 + Vx×1000 + Vy×1000 + Vz×1000 + BCC + 0x7D |
| 上行帧（STM32→K7） | 24 字节：0x7B + 状态 + 编码器×6 + 加速度×6 + 陀螺仪×6 + 电池×2 + BCC + 0x7D |
| 速率 | 下行按需，上行 20Hz |
| 与 wheeltec ROS2 协议 | **完全兼容**，`turn_on_wheeltec_robot` 包的串口框架可直接复用 |

## 关键硬件引脚

| 功能 | 引脚 | 说明 |
|------|------|------|
| 串口控制（ROS 模式） | USART3: PC10(TX), PC11(RX) | K7 → CH9102F → USART3 |
| IMU | MPU6050 (I2C) | 6 轴姿态传感器 |
| 电机驱动 | D50A（BTN7971 双路） | 2 轮差速 |
| 编码器 | 正交编码器 (TIM) | 电机反馈 |
| 电池电压 | ADC1 | 电压监测 |

## 与 K7 的连接

```
K7 (RK3576)                     C50X 底盘
┌──────────┐         USB        ┌──────────────┐
│ USB Host │ ←─── Type-C/A ───→ │ CH9102F → USART3 → STM32F407 │
└──────────┘                     └──────────────┘
                                   ｜-- 电机(BTN7971)
                                   ｜-- 编码器
                                   ｜-- MPU6050
                                   ｜-- 红外测距×3
```

> USB 电缆直连即可，CH9102F 芯片内部处理电平转换，**不需要额外电平转换模块**。
