# K7 (RK3576) 上手操作指南

> 从零开始，完成烧录、串口调试、网络配置、SSH 无线连接、VS Code 远程开发的全部流程。

---

## 一、准备工作

| 物品 | 说明 |
|------|------|
| K7 主板 + 电源 | 12V–24V DC 适配器（3S 锂电池也可） |
| **可传数据的** Type-C 线 | USB-A to C 优先，廉价充电线可能无法传数据 |
| Windows PC | 安装烧录驱动和工具 |
| USB 转 TTL 模块 | CH340 / CP2102 / FT232 均可，首次调试用 |
| Ubuntu 镜像 | 从 [doc.kickpi.cn](https://doc.kickpi.cn) 下载 `update-*.img` |

## 二、烧录镜像到 eMMC

### 1. 安装 USB 驱动

```
rk3576_data\5-DevelopmentTool\win_x64_UsbDriver\DriverAssitant_v5.13.zip
  → 解压运行 DriverInstall.exe
```

### 2. 运行 RKDevTool

```
rk3576_data\5-DevelopmentTool\win_x64_UsbImageBurnTool\RKDevTool_v3.30_for_window.zip
  → 解压运行 RKDevTool.exe
```

### 3. 进入 Loader / MASKROM 模式

> **数据线选择**：Type-C to C 线偶发安装失败；推荐使用 **USB-A to C** 数据线，更稳定可靠。

RECOVERY / MASKROM 为同一个按键，触发后 RKDevTool 会显示 **"Found One LOADER/MASKROM Device"**。

**方式一：断电上电法（推荐）**

1. K7 **先断电**
2. **按住 MASKROM 键不放** → 接通电源
3. 绿色 LED 常亮后 → 松开 MASKROM 键 → 连接 USB 烧录线
4. RKDevTool 检测到设备即可

**方式二：复位法（板子已通电时）**

1. 板子已通电，USB 线已连接
2. **按住 MASKROM 键不放** → 短按一下 **RESET** 键
3. RKDevTool 检测到设备后 → 松手

> 如果没识别到：① 驱动装了吗 ② 换 USB-A to C 数据线

### 4. 烧录

1. 切换到 **「升级固件」** 标签页
2. 点击 **「固件」**，选择下载好的 `update-*.img`
3. 点击 **「升级」**，等待完成
4. 烧录完毕后板子自动重启
5. **绿色 LED 常亮 + 蓝色 LED 持续闪烁** = 系统就绪

> 升级模式自带覆盖效果，无需手动擦除 eMMC。

## 三、串口连接（首次调试）

### 接线

| TTL 模块 | K7 DEBUG 口 |
|----------|-------------|
| GND（黑） | GND |
| TX（绿） | RX |
| RX（白） | TX |
| VCC（红） | **不接！** |

> TX/RX 交叉连接。如果无输出，交换 TX/RX 再试。

### MobaXterm 设置

1. 打开 MobaXterm（`rk3576_data\5-DevelopmentTool\win_x64_UartDebugTool\`）
2. Session → **Serial**
3. 选择对应 COM 口
4. **Speed = 1500000**（注意是 1.5M）
5. 给 K7 上电，启动日志开始输出

### 登录

系统默认自动登录 `kickpi` 用户，无需输入密码。如需手动登录：用户名 `kickpi`，密码 `kickpi`。

## 四、网络配置

### 当前方案：WiFi 无线连接

1. 配置 WiFi 连接：

```bash
sudo nmtui
```

2. 选择 `Activate a connection` → 找到你的 WiFi → 输入密码 → 连接
3. 设置开机自动连接：

```bash
sudo nmcli connection modify "你的WiFi名" autoconnect yes
```

4. 查看 WiFi IP：

```bash
ifconfig wlan0
```

5. **重启板子**（WiFi 配置需重启生效）。之后拔掉所有线缆，仅上电即可。

> 重启后 IP 可能变化，建议到路由器后台查看 DHCP 列表，或给板子设置静态 IP（路由器端绑定 MAC）。

### 备选方案：网线直连 PC（无路由器时）

**PC 端（Windows）：**

1. 控制面板 → 网络和共享中心 → 更改适配器设置
2. 右键有线网卡 → 属性 → 双击「IPv4」
3. 使用下面的 IP：`192.168.10.1`，子网掩码 `255.255.255.0`，网关留空

**K7 端：**

```bash
sudo ip addr add 192.168.10.2/24 dev end0
```

之后在 PC 上 `ssh kickpi@192.168.10.2` 即可。

## 五、SSH 连接

确定 K7 的 IP 后，Windows 终端直接连接：

```bash
ssh kickpi@<K7的IP>
# 密码: kickpi
```

首次连接需确认指纹（`yes`）。连接成功后即可拔掉串口线，日常使用只需 SSH。

### SSH 掉线优化（可选）

编辑 `C:\Users\<用户名>\.ssh\config`，添加：

```
Host k7
    HostName 192.168.x.x
    User kickpi
    ServerAliveInterval 60
```

之后 `ssh k7` 即可连接，心跳保活防止空闲断连。

## 六、VS Code 远程开发

### 1. 安装扩展

VS Code → `Ctrl+Shift+X` → 搜索 **Remote - SSH**（作者 Microsoft）→ 安装。

### 2. 配置主机

`F1` → `Remote-SSH: Connect to Host...` → `Add New SSH Host...` → 输入：

```
ssh kickpi@192.168.x.x
```

选择配置文件 `C:\Users\<用户名>\.ssh\config` 保存。

### 3. 连接

`F1` → `Remote-SSH: Connect to Host...` → 选择对应 IP → 输入密码 `kickpi`。

首次连接会在远端安装 VS Code Server，稍等片刻即可开始编写代码。
