## 一、更新规范（后续日志必读）

### 1.1 记录形式

**推荐直接编辑本文档**（`work_logs/工作日志汇总.md`），不再生成 PDF。若仍需 PDF，先用 Markdown 写好，再导出为 PDF，文件名：`MMDD日志.pdf`。

### 1.2 每条日志必须包含以下四栏

```markdown
### 日期（例如：0614）

#### 感知组
- **本周进度**：
  - xxx
  - xxx
- **本周任务**：
  - xxx
  - xxx
- **本周问题**：
  - xxx（可选，没有就写“无”）

#### 控制组
- **本周进度**：...
- **本周任务**：...
- **本周问题**：...

#### 避障组
- **本周进度**：...
- **本周任务**：...
- **本周问题**：...

#### 本周总结（可选）
- 跨组协调事项、老师指导意见、下周重点。
```

### 1.3 写作要求

- **只写结论和可验证的事实**，不写“看了很多资料”“学了很多东西”等模糊描述。
- **任务必须可验收**：有代码/文件/测试结果/图表即为完成，否则不算完成。
- **问题必须具体**：不要写“有点困难”，要写“A 模块编译报 xxx 错”。
- **新日志追加到本文档末尾**，不要另起新文件，方便全文检索。

## 二、历史关键决策与背景

阅读旧日志后，需要注意以下背景，它们直接影响当前 `K7_ros2` 架构设计：

1. **原平台是 STM32 + LabVIEW/myRIO**：
   - 控制组在 STM32 上写 C 语言：PID、APF、Stanley、A* 路径规划。
   - 避障组用 LabVIEW/myRIO 读取三个红外传感器。
   - 感知组用 LabVIEW 做卡尔曼滤波和小车位置可视化。
2. **05 月底开始转向 ROS2**：
   - 0524 安装 WSL+Ubuntu+ROS2，学习 ROS2 通信机制。
   - 06 月开始讨论“深度相机选型”，从红外避障向视觉感知过渡。
3. **当前状态（截至 0614）**：
   - 控制组：正在把卡尔曼滤波、APF、Stanley、循迹等代码整合进 STM32 主程序，尝试编译通过。
   - 感知组：卡尔曼滤波 C 代码已完善，开始学习 ROS2 和双目相机。
   - 避障组：红外传感器已完成定位算法和 C 程序，正在解决芯片手册/接线/烧录问题。
4. **与现有 K7 架构的关系**：
   - 原 STM32 上的 APF/Stanley/循迹/A* 需要决定是否保留在 STM32 内，还是上移到 K7 的 ROS2 层。
   - 红外传感器目前固件不上报数据（见 `CLAUDE.md` 13.3），要重新打通或改用深度相机。
   - 卡尔曼滤波在 ROS2 层可用标准包 `robot_localization` 替代，感知组需从“手写 C 代码”转向“调包+调参”。

   - STM32 层继续跑手写 C 代码。
   - K7 ROS2 层使用 `robot_localization` 标准 EKF 包。
